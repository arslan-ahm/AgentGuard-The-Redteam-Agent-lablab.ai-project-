# ComfyUI workflows

Save every ComfyUI workflow used for AgentGuard media here as JSON (ComfyUI: Workflow → Export). Name it by what it makes, for example `studio_background.json`. Generated images go to `media/comfy/output/` (gitignored) and are referenced from a brief's `background` field.

Only backgrounds, textures, props and scenes are generated. Text, the logo and the product image are never generated (see `media/CLAUDE.md`).
