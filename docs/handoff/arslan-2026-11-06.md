- `backend/app/policy/url_policy.py`: `UrlValidator` (implements `UrlPolicy`).
  - Blocks: http/https only; credentials in URL; control characters; internal hostnames; every resolved address must be public (loopback, RFC1918, CGNAT, link-local, metadata, multicast, ULA, IPv4 hidden in IPv6 via mapped/6to4/Teredo/NAT64); inet_aton shorthand (`127.1`, `0x7f000001`, `2130706433`).

  - Flags: `--rm`, read-only root, noexec tmpfs, `--cap-drop=ALL`, no-new-privileges, cpu/mem (no swap)/pids/nofile limits, dedicated network only, only `/in:ro` + `/out` mounted (system dirs and `docker.sock` refused).
  - Lifecycle: policy re-check before launch; hard wall-clock kill; `docker rm -f` in `finally`.
  - Result handling: `result.json` is validated, and exit 3 forces `blocked`.
  - Untrusted `out/`: symlinks and special files are deleted (never followed); `result.json` over 5 MiB is never read.
