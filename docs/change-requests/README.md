# Change requests

Cross-module or contract changes (PROJECT_BRIEF.md section 8). Never edit another owner's module or a section 5 contract directly. Copy the template below to `CR-<n>-<short-name>.md`, using the next free number.

```markdown
# CR-<n>: <short name>

- Requested by: <name> (<module>)
- Date: <YYYY-MM-DD>
- Status: proposed | approved | rejected | implemented

## What
## Why
## Proposed contract diff
## Impact (modules, tests, demo)
## Stub/mock used meanwhile

## Approvals (required: owner of affected module; contract/architecture changes: Arslan AND Sarah)
- [ ] <name>, <date>
- [ ] <name>, <date>
```

Switch from the stub to the real change only after the approvals above are recorded.
